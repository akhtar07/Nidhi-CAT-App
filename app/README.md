# Ascent — frontend

React 18 + TypeScript (strict) + Vite + Tailwind CSS + shadcn/ui. See
`/SPEC.md` and `/PROGRESS.md` at the repo root before making changes.

## Local development

```sh
npm install
npm run dev
```

## Checks (also run in CI)

```sh
npm run lint
npm run typecheck
npm run build
```
